# Local Bridge as permanent universal playlist for all downloaded Tracks

Every downloaded Track is added to a single user-configured "Local Bridge" playlist, regardless of whether the Music Request also specifies Album Playlists or other organisation. This is not a staging area — it is the permanent home for all local file Tracks.

The reason is cross-device sync: Spotify's local file streaming is tied to playlists saved to the user's account. By adding every Track to the Local Bridge, other devices signed into the same account can download the Track for offline listening without the user manually saving individual Album Playlists on each device.

Album Playlists and other Playlist Actions are additive — a Track appears in both the Local Bridge and any additionally requested playlists.
